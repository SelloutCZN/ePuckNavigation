This repository contains the relevant code and files used to control an e-puck robot to complete two independent tasks:

1) Navigate obstacles in a closed area (https://youtu.be/nfRcDoxO5vg) 
2) Find and chase an object in an open area (https://youtu.be/Vmz1d07rDzc)

This work was completed as part of project work in the ELE466 module at the University of Sheffield (2025-26). 
Source code may be found under Project/main.c 

Documentation on the e-puck robot can be found here: https://e-puck.gctronic.com/
